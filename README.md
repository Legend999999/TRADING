# Gold Framework

Responsive XAU/USD trading workspace with a TradingView chart, timeframe controls,
and a Gann workbench for Square-of-Nine levels and trade setup planning.

## Prerequisites

- Node.js `>=22.13.0`

## Scripts

- `npm run dev`: start the Next.js development server
- `npm run build`: build the production Next.js app
- `npm run start`: start the built production server
- `npm test`: build and verify the important Gold Framework UI source is present

## Project Shape

- `app/page.tsx`: trading workspace and calculators
- `app/globals.css`: responsive application styling
- `app/layout.tsx`: metadata and fonts
- `public/`: static icons
